# FlowSave 0.3 · 流影下载

基于 Jvust2/yt-dlp 的 Android 媒体保存工具。界面、Python 桥接和自建服务器示例位于本仓库；不修改上游 yt-dlp 项目。

## 这个版本的准确能力

- **视频 / 音频**：最高可用、2160P / 1080P / 720P 上限、兼容 MP4、仅音频。最高可用不再为了 MP4 降到较低分辨率。它是当前权限、当前网络下平台暴露的格式，不是作者上传母版。低档位不存在时明确报错，不偷偷超过限制。
- **无损整理**：内置 Android FFmpeg，复制已编码的数据流，不重新编码。VP9 / Opus 等不兼容 MP4 的组合使用 MKV；手机自带播放器可能不支持，需要兼容的播放器。
- **图片 / 图集**：接入 gallery-dl，支持它能解析的 Instagram / TikTok / X 单条图文及图片直链。抖音只解析页面中当前作品的正文图集，标记为实验性；页面未提供、登录/验证码阻止时会失败，绝不拿封面冒充图集。单任务上限100张、单张64MB。图片原字节保存，不重新压缩，不承诺平台提供上传原图。
- **封面**：独立入口，保存 yt-dlp 返回的最高可用封面。
- **保存**：图片进入 `Pictures/FlowSave`；音视频进入 `Download/FlowSave`。部分失败会显示已保存数量和提醒。
- **网络**：默认直连；可选自己的 HTTP(S)/SOCKS5 代理，或兼容的 HTTPS 自建服务器。**没有免费节点、公共代下载服务，也没有自动部署服务器。** 网络配置通过 Android Keystore 加密，Cookies 保存在应用私有目录。
- **隐私**：选择自建服务器意味着把链接与文件交给自己的服务器处理；手机的 Cookies 和代理凭据不会随任务上传。仅 HTTPS+令牌，不跨域重定向认证请求。

## 兼容性与限制

Android 7.0+，arm64-v8a / x86_64。当前为 Debug 签名测试版，不是商店正式发布版。与旧版签名不同时需卸载旧版；卸载会清除登录和配置，应先保留重要应用数据。公共相册/下载目录中的文件请自行备份。

没有后台下载服务，任务期间保持页面开启。六个平台的提取器并不等于每条链接都可下载；账号、地区、反爬、JS验证、会员权限和DRM均可能阻止下载。应用不提供认证/付费权限/DRM绕过。

## 构建与源代码

CI 先从本分支的版本化传输包展开0.3源文件并提交到同一分支，再构建；因此源码目录与实际编译版本一致。传输包不是运行时更新机制，也不包含任何凭据。每次构建的来源SHA与依赖版本记录在 `build-manifest.txt`。

环境：JDK17、Gradle8.10.2、Android SDK35、NDK27、Python3.13。

```
python -m unittest discover -s tests -v
gradle -p android-app assembleDebug
```

首次手动构建需从 `Jvust2/yt-dlp` 复制 `yt_dlp` 包，并按工作流编译/放置 `libqjs.so` 与 `libffmpeg.so`；完整构建步骤以 `.github/workflows/android-v03.yml` 为准。

GitHub Actions 产物包括APK和完整源代码包。完整源代码包包含实际使用的 yt-dlp、gallery-dl源码发行包、FFmpeg和QuickJS源代码，以及构建脚本与许可。

## 可选自建服务器

详见 `server/README.md`。手机不必使用系统VPN，但需要能够直连该HTTPS服务器，且服务器能够访问目标平台；不保证所有网络可达。服务器与域名、带宽由部署者提供，仓库不会替用户购买、部署或运行服务。

## 验证边界

单元测试覆盖格式选择、图片签名、Cookies不上传、凭据脱敏、目标域检查与私网地址拦截。合并测试比较合并前后的音视频包SHA256；CI模拟器测试启动APK、QuickJS、FFmpeg与VP9+Opus合并。它们不是六个平台的真实下载成功证明。没有用户账号/指定链接/真实手机，仍需实际使用验证。
